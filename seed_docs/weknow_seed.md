# WeKnow 项目说明

WeKnow 是一个基于开源 RAGLite 深度研读与二次开发构建的检索增强生成系统。
检索内核沿用 RAGLite 1.1.1，架构设计参考腾讯 WeKnora 与 LightRAG 的公开思路。

## 存储与检索

系统不引入独立向量数据库，向量直接存在关系型数据库里，支持两套后端。
默认后端是 DuckDB，它通过 vss 扩展提供 HNSW 近似最近邻索引，通过 fts 扩展提供 BM25 全文检索。
备选后端是 PostgreSQL 加 pgvector 扩展，关键词检索走 tsvector 加 GIN 索引。
向量列使用定长数组类型 FLOAT[N]，维度在运行时由嵌入模型决定。

## 文档处理链路

文档解析采用引擎注册表模式，按引擎和文件类型两级映射选择解析器，并提供三级回退机制。
内置解析器覆盖 28 类文件格式，其中 docx、pptx、xlsx、epub 用标准库直接解析 OOXML 与 OCF 容器，因此零新增依赖。
可选引擎包括 pandoc、markitdown，以及多模态引擎和 Mistral OCR。

## 文本切分

切分分为三层。第一层是句子切分，使用 Segment any Text 模型判断句子边界。
第二层是块元切分，使用动态规划求解最优切分点。
第三层是块切分，使用二分整数规划，并移除话语向量方向的成分以提升语义一致性。

## 检索融合

在线检索走混合路线，向量检索与关键词检索的结果用倒数排名融合合并，融合常数取 60。
融合之后可选地经过交叉编码器重排，再按块跨度合并相邻块返回上下文。
